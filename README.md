# ATLAS IPS — Web Pembelajaran IPS SMP

Aplikasi pembelajaran IPS untuk siswa SMP berbasis **Laravel 13 + MySQL**.

## Fitur yang tersedia

- Daftar Bab dan Materi pembelajaran.
- Nomor Bab dan Materi diatur manual saat membuat/mengedit data.
- Nomor dirapikan kembali setelah data Bab/Materi dihapus.
- Materi teks.
- Video pembelajaran melalui:
    - Upload video sendiri (MP4/WebM/OGG, maksimal 200 MB).
    - YouTube.
- Referensi materi melalui:
    - Link eksternal.
    - File PDF.
- Pencarian materi.
- Navigasi materi sebelumnya/berikutnya.
- Satu akun/role Admin untuk pengelolaan konten.
- Pengguna/siswa dapat mengakses materi tanpa akun.
